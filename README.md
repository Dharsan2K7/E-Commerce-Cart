# 🛒 Modern E-Commerce Cart

A modern and responsive Shopping Cart web application built using **HTML, CSS, and JavaScript**. This project allows users to browse products, add items to the cart, update quantities, remove products, and calculate the total price. Cart data is stored using **LocalStorage**, so items remain saved even after refreshing the page.

---

## 🚀 Features

✅ Attractive and Interactive UI  
✅ Responsive Design for Mobile & Desktop  
✅ Product Listing Section  
✅ Add Products to Cart  
✅ Increase / Decrease Quantity  
✅ Remove Individual Items  
✅ Auto Total Price Calculation  
✅ Clear Entire Cart  
✅ Save Cart using LocalStorage  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- LocalStorage API
